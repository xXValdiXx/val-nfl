# val-nfl

Userscript de Tampermonkey del análisis NFL de Val (Sofascore + Playdoit + ESPN). Aparte del de fútbol (`val-futbol`). Se actualiza solo desde aquí.

Instalar una vez (abrir el enlace con Tampermonkey activo y pulsar "Instalar" o "Reinstalar"; reemplaza al que instalaste desde archivo):

- Panel de Val · NFL: https://raw.githubusercontent.com/xXValdiXx/val-nfl/main/val-nfl.user.js

Tampermonkey revisa si hay versión nueva (por defecto cada día) y la instala cuando sube el número de `@version`. Para forzarlo: Tampermonkey → Panel de control → Utilidades → "Buscar actualizaciones".

Los datos (equipos, jugadores, resultados) los baja el propio panel de [nflverse](https://github.com/nflverse/nflverse-data); este repositorio solo guarda el script.
